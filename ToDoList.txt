三、当前阶段的游戏定位与版本边界
------------------------------------------------------------
定位：鼠族文明复兴题材的经营放置游戏；乐趣来自生产瓶颈的理解、旧产业价值延续、
建设与研究之间的取舍，以及跨时代后出现的新经营问题，而不是手动点击数量或系统数量。

本版要兑现的体验承诺：
  1. 开局十分钟内，玩家能说明“我缺什么、为何缺、下一步去哪里解决”。
  2. 从 Animal 到 Industrial 的三个时代门由真实资源、建筑和科研完成，不靠赠送完成状态。
  3. 工业阶段购买一次关键工坊后，玩家能观察到相应建筑/生产链的实际改变。
  4. 离开再回来，玩家理解离线收益、停滞原因与下一目标；不会重复结算或无提示丢失进度。
  5. 早期验收通过后，Spacer 首次殖民、远征和维修构成明确的小目标，不直接抛给玩家整个深空后盘。

暂不纳入本版：Ultra/Archotech 新内容、即时战斗、外交/角色技能/随机事件大系统、
第二套任务系统、重置/转生系统、自动建造策略系统、模拟器路线搜索、联网商业化功能。
这些不是“永远不做”，而是本轮没有足够证据证明比修通现有体验更值得做。

九、始终不变的设计护栏
------------------------------------------------------------
- Food 唯一库存上限；没有普通资源仓库、隐藏库存 Clamp 或扩仓门槛。
- 不重引 workforce；人口、生产力、领土、电力、物流各自保持清晰语义。
- 旧工业要继续有价值；不为每种材料造一座轨道替代厂。
- 新资源必须有可达来源、两种有意义消费或一种战略消费；新科研有真实效果。
- 普通建筑几何成本，批量购买用现有闭式大数计算；奇观/唯一建筑的数量约束另行表达。
- 星区主要提供领土、原料与有限战略流，不能替代玩家先进加工链。
- 普通 UI 用 Scene/Prefab 创作；运行时只绑定，重复数据项按现有许可生成。
- 保留所有稳定 ID/GUID；不把 UI 缓存或显示数值变成权威状态。
- Story 是文明记忆，不是经济奖励系统；当前 Ultra/Archotech 仍冻结新增内容。

十一、第二轮深审修订：先处理真实入口与升级合同
------------------------------------------------------------
本节优先于首轮概述；不增加重复任务，D01-D12 是前述 21 项待办的证据细分。
完整源码行号、触发链、反证、最小验证与验收见 outputs/DeepAudit.txt。
分级：A=源码确定的行为/契约/验证问题；B=特定条件风险；C=需策划选择的多目标取舍。
所有验证规格均待 Unity 执行，不是已经复现的运行结果。

[ ] D01 → P0-04 [A，高] 旧档磁盘入口与内部恢复合同不同。
  SaveFormat 接受 v5-v8，但 TryReadPath 对所有版本强制要求 Story；
  ApplySaveData 则允许 Story 缺失，旧版测试直接调用后者绕开文件入口。
  做法：通过公开 LoadOrCreateGame 验证旧格式迁移；v8 缺 Story 仍应严格拒绝。
  不能将“版本号被接受”继续描述为全部旧档已兼容；先定迁移政策并保留原文件。

[ ] D02 → P0-04 [B，高] 好备份恢复后，下一次保存先把坏主档复制到备份。
  若随后替换主档失败/进程退出，两个正式候选都可能不可用；tmp 未进入加载候选。
  做法：设计备份来源与提交阶段，不用未经验证主档覆盖最后有效备份；故障点逐一注入验证。
  正常完整保存成功仍有有效主档，不把该条件风险说成每次保存都会丢档。

[ ] D03 → P0-04/P1-07 [B，中高] 暂停保存失败而进程存活，恢复可能重复计算在线时间。
  ApplyOfflineProgress 只读最近成功保存时间，暂停时 SaveNow 的失败返回未参与判断。
  做法：分离持久化时点与当前内存已结算/暂停时点；分别测存活恢复与重启恢复。

[ ] D04 → P2-04 [B，中] 工坊效果提交异常时资源回滚，但 Purchased 缺少域回滚。
  WorkshopManager 在回调里先置 Purchased=true，再重建效果，没有提供 rollbackState。
  做法：复用 ResourceManager 现有补偿接口，验证库存、购买标记、倍率及派生速率一起恢复。
  当前资产未发现该异常正在触发，不据此推倒事务架构。

[ ] D05 → P0-02/P1-10 [A，高，待实施方案] E08 不只是新增工厂选项。
  CanConstructNew 仅允许升级链最高已解锁层；挂上 upgradeTo 后，旧厂会停止接受新建。
  做法：升级方案必须覆盖解锁前后、部分/全部升级、拆尽旧厂、存读档六态；
  不能依赖“升级后还随时能补建老 WireMill/建材厂”兜底铜线和陶瓷。

[ ] D06 → P0-02/P1-10 [A，中高] 定向建筑加成不会自动沿升级链继承。

  不会自动附着于新定义。“新厂基础 4x”不等于玩家当前实际产率 4x。
  做法：列完整效果绑定、净产率/维护与投资保留合同；不要简单复制所有加成造成重复收益。

[ ] D07 → P0-03-C [C，中] 大学与深空观测站是科研/军事复合角色选择。
