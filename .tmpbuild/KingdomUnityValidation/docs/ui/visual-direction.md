# Visual direction worksheet

## Recommended starting direction

A dark, low-saturation medieval strategy interface with restrained gold accents. Readability of large numbers and rates takes priority over ornamental texture.

This is a recommendation, not a locked art direction.

## Decisions required before final visual implementation

- target references/screenshots;
- primary and secondary fonts plus licenses;
- icon source and license;
- Chinese-only or multilingual layout;
- minimum supported resolution;
- desired information density;
- animation intensity;
- whether parchment texture is desired or only subtle framing.

## Proposed semantic tokens

- BackgroundPrimary
- BackgroundSecondary
- Panel
- PanelRaised
- Border
- TextPrimary
- TextSecondary
- Accent
- Positive
- Negative
- Warning
- Locked
- Completed
- Selection

## Proposed spacing scale

`4 / 8 / 12 / 16 / 24 / 32`

## Proposed component states

Normal, Hover, Pressed, Selected, Disabled, Locked, Waiting, Completed.

Never communicate an important state by color alone.
