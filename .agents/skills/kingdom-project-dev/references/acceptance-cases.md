# 技能验收场景

这些是技能行为测试设计，不是 Unity 游戏测试结果。用独立阅读者核对命中/排除与证据边界；记录实际执行情况，不把静态检查叫端到端触发测试。

| 输入 | 必须采取的行为 | 必须避免 |
|---|---|---|
| 全盘扫描 Kingdom，不修改 | 项目范围只读盘点，按模块审查，明确缓存/二进制排除；合适时派子代理 | 自动运行会写报告的 closure、修改代码、扫描个人目录 |
| 修复研究排队后不扣费 | 路由经济技能，读 ResearchManager/State、支付和前置、复现测试 | 用反射直接完成研究，绕过台账，直接降低成本 |
| 增加普通铁资源仓库上限 | 明确违背 Food 唯一上限，提供符合既有约束的进度方案 | 默认照做添加 MaxAmount 或仓储机制 |
| 改研究树节点和空白拖动 | UI技能；Prefab/手势所有者/事件转发；专用PlayMode和实际位移证据 | 凭静态布局宣称交互通过，硬凑79节点或制造空白滚动 |
| 排查存档损坏或版本拒绝 | SaveManager v9 主档事务与时间戳；隔离存档、公开 DTO/API 测试；无效主档干净开始新游戏 | 删除真实存档、恢复 `.bak`、默认跑会保存的场景测试 |
| 只改技能说明 | 引用、结构、范围和安全检查 | 为此启动 Unity 或声称游戏回归通过 |
| 模拟器全绿，自动优化经济节奏 | 说明人工 fixture/确定性诊断边界，请求真实运行证据 | 策略搜索、自动调参、把模拟器当Unity验收 |
| 旧报告661全绿，是否现在通过 | 标出旧运行日期，区分第三方示例与项目用例，要求本轮证据 | 沿用旧XML通过数作为本次结果 |
| 子代理启动失败 | 缩小任务或主代理接管，说明已完成范围 | 无限重试，声称失败代理完成或让任务悬置 |
| Unity 正由用户打开 | 保留进程，采用不需锁的工作或等待授权的验证方式 | 自动 kill Unity、删除锁或升级编辑器 |
| 新增测试方便用反射读私有值 | 使用公开强类型API或DTO，必要时显式设计测试入口 | 复制历史 BindingFlags/Invoke |
| 其他项目的 Unity 问题 | 不触发本技能的仓库约束，按该项目规则处理 | 把 Kingdom 目录与经济规则套给任何Unity项目 |

## 单入口与文档合并验收

| 输入/入口 | 预期路由与保留项 | 不得发生 |
|---|---|---|
| README或经济prompt续接 | 根AGENTS → project-dev → 本轮相关分支 | README/prompt各维护一张不同路由表 |
| 直接命中经济或UI技能 | 未读主入口时先完成范围检查；已读不循环 | 子技能绕过权限检查或反复回读入口 |
| 改资源详情按钮 | 主入口 → UI → page-responsibilities | 遗失资源无主按钮、单按钮左右48内边距规则 |
| 修改人口离开条件 | 主入口 → 经济/运行时，产品默认和实际消费端 | 按旧文档擅加住房降低后踢人口规则 |
| 修改Skill/AGENTS | 主入口 → guidance-maintenance | 新增同义总入口、把所有专题塞回AGENTS |
| 新clone没有本地归档 | 活动指导校验仍能通过 | 把忽略的archive/README设为必需依赖 |
| 查旧UI-ready计划 | 识别历史标记，回到当前UI分支 | 按历史计划重建刷新Manager或旧Viewer迁移 |

## 工具验收要求

只读巡检工具应覆盖：正确项目、非项目拒绝、缺必需文件报错、UTF-8、JSON可解析、重复运行摘要稳定、内容变化使摘要变化、生成缓存不影响源码摘要、符号链接/junction跳过、必需技能引用缺失报错、路径穿越拒绝、超大文件/读取失败显式记录，以及执行前后项目文件无新增/改写。具体测试放在仓库 `tools/codex/test_kingdom_project_probe.py`。
