# 研究角色分类与设计判断

更新：2026-10-07。保留分类方法，删除129节点/Ultra1条、旧扇出与叶子统计；它们不覆盖后续Ultra工程与能力内容。

| 角色 | 判断依据 |
|---|---|
| 开新链 | 完整前置满足后，某资源首次有可建生产者或某行为首次可用 |
| 解除约束 | 电力/物流/食物/人口生产力等当前限制得到实际缓解 |
| 旧产业提效 | 真实目标建筑/资源/全局消费端的收益改变 |
| 时代门 | 完成后推进真实TechLevel或关键系统准入 |
| 叶子/支线 | 即使没有后继，只要有真实可消费价值就可保留 |

角色可重叠。不能按研究名称、最浅前置或最深前置单一极值归因；先判断整个前置集合和生产者首次可建时点。
不能把静态扇出高解释为玩家完全没有选择，也不能仅为“叶子”强行加后继。
新研究优先产生可解释能力/取舍；若现有研究和工坊已承担职责，就不新增同义节点。
完成前能理解效果，完成后真实结算改变；当前倍率要含已有投资与供给状态。
入口：Assets/Resources/Datas/Research/及Building/Workshop，Manager/ResearchManager.cs与ProgressionModifierManager.cs。
