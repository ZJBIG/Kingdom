应优先处理的六项问题

  1. 奇点入口仍存在显著成本集中风险。现值 5.5e11，全部 47 项 Spacer 研究 BaseCost 合计 3.82437e10，比例约 14.38 倍。这不是“耗时必定是整个时代的 14.38 倍”，因为研究力会变；但足以要求专门校准入口。下一时代研究还受 2/3 速度系数影响。[S1、S2]
  2. 入口后才获得的增益，不能帮助跨过入口。不能用“Ultra 会加更强科研建筑”解释 Spacer 玩家为何付得起奇点。应先测门前实际研究速度，决定调整入口费用，或加强已可达的门前科研；两者均需另行实施授权。
  3. 量子科研升级存在价值继承风险，而不是“缺一个中档科研建筑”。已有 DeepSpaceObservatory → QuantumComputingArray → InterstellarTheoryNexus，基础研究力 220 → 500 → 900。高级层前置满足后，低层不能再新建；既有定向效果按具体建筑取值，不自动继承。新增 Ultra 科研若继续挂 upgradeTo，可能让昂贵量子纠错投资失去后续增建对象。须测“升级前后净研究力、维护、领土、军事实益”，不能只看 500 和 900。[S3]
  4. 文字有一处已证实未同步。MatterStateControlTheory 仍写“提高拆除返还”，当前只有 Type 5 建造效果，返还条目已删除。应先统一文字与实际效果，避免 Ultra 文案承诺再膨胀。[S4]
  5. 不能把 DeepSpaceRelay 的 25−48 直接判成负收益 bug。原始物流产/耗是 25/48，但实际产出还乘全局、定向倍率，且它另给舰队能力。必须按解锁时全部必需研究/工坊计算净物流和军事实益后定案。[S5]
  6. “只配置资产”做不出完整暗森林或水滴机制。当前战役是战力比、持续补给、推进、伤亡；没有相互作用类型克制、传播延迟、暴露度、探测可信度或文明外交状态。把新敌人强度写得极大，仍只是数值墙。[S6]
额外的终局循环陷阱：当前 10 个星区全部 repeatable=0。不要只把新星区改成 true 就上线。TryOccupy 可在已占领且可重复时继续调用奖励，方法本身不重置已完成进度，默认奖励还包含领土；另外活动战役恢复校验排斥“已占领且活动”的状态。须先定义并测试每轮重置、奖励幂等、重复领土、补给递增和存档契约。这是拟启用新功能时的风险，不是当前不可重复星区已被证实发生刷奖。[S7]

2. 借鉴《三体》：借约束与冲突，不直接搬能力清单

建议统一设定语言：已知物理 → 尚未完成的工程外推 → 明示的虚构突破。小说的设定可以做创意来源，但不是证明这些技术真实可造的科学文献；以下不使用小说原文引述，也不声称复现小说世界的全部技术规则。

灵感理论边界Kingdom 的适配方式不建议
智子 / 科研受干扰量子测量、纠错、实验复现有真实基础；把质子展开为智能工程体属于小说设定。量子纠缠不能独立传递可控超光速信息。做“跨设施实验复核、结果可信度、重复验证”，让计算、能源与材料服务实验；量子纠错系统已存在，应延伸其角色而非重建。永久锁死研究；随机让玩家几天投入归零；“量子通信=瞬时通信”。
水滴 / 材料代差强相互作用是真实相互作用；可常温稳定、任意宏观形状、近乎不可破坏的强相互作用材料是科幻假设。原创“宏观束缚态材料”：小样可造、批量稳定难、需要供能与维护。先服务设施与舰体，再谈特殊战术。一造出来全战役秒杀；既便宜又无维护的万能材料。
曲率推进 / 航迹广义相对论的时空曲率有理论基础；可用推进器、能量条件及小说式航迹不是已验证工程。相位航行 → 度规测量 → 小尺度场约束试验 → 有限用途的曲率工程。首阶段不承诺超光速或时光倒流。仅做“物流+10%”却写成瞬间星际穿越。
引力通信引力波按光速传播；检测存在不等于文明拥有可用发射器，更不等于超光速通信。延续现有引力通信理论的时钟同步、校准与研究协同；更高功率信标作为后期工程议题。把当前引力通信研究重新解释成已实现曲率或超光速。
黑暗森林 / 宇宙社会学是建立在若干前提上的科幻推演，不是经证实的宇宙定律。把“信息不完全、信号可探测、远距离响应不及时”转成有预警、有选择的战略压力。宣布所有文明必定互相毁灭；离线期间无预警清档。
二向箔、黑域、小宇宙属于高度虚构的世界规则，不能从现有工业加几级倍率自然推得。Ultra 留作异常记录或失败实验线索；真正改变维度、因果与宇宙边界留到 Archotech 再立项。用降维攻击跳过所有建设与补给，提前耗尽后时代空间。
推荐的原创总命题：祖先留下的并非万能技术，而是一组只在特定材料、能源和组织条件下成立的实验。鼠族开始发现：文明的强大，不在于能否启动装置，而在于能否重复验证、稳定运行，并承担它向宇宙发出的信号。

物理边界核对：IBM Quantum 的量子隐形传态教程明确需要经典通信，传递的是量子态而非物质；NASA Space Place 明确引力波以光速传播。其余虚构能力在本文均作为设计假设，而非技术现状判断。[E1、E2]

3. 现有线路：Ultra 应从这里接，不另起炉灶

以下为当前实际节点的关键依赖摘录，不是把多前置科技简化成唯一线性链。技术奇点的四项直接前置已在资产和测试中明确。

计算与协同：QuantumComputing（量子计算）
          + GravitationalCommunicationTheory（引力通信理论）
          + DeepSpaceSystemsTheory / DeepSpaceIndustrialIntegration
          → InterstellarKnowledgeCoordination（星际知识协同）

材料与场控制：PhantomMaterials（幽影材料工程）
          → PhaseMaterialEngineering（相位材料工程）
          → MatterTransmutationTheory（高能材料重构理论，另需计算/电网）
          → PhaseFieldNavigation（相位航行，另需计算/相位材料）
          → PhaseFieldStabilizationTheory（相位材料耐久理论，另需战役时序）
          → MatterStateControlTheory（材料生命周期控制）

奇点直接前置（全部满足）：
QuantumComputing + PhaseFieldNavigation
+ MatterStateControlTheory + InterstellarKnowledgeCoordination
→ TechnologicalSingularity → Ultra

现有命名已经主动限制能力：高能材料重构“不直接实现资源互换、反物质或湮灭能源”；引力通信“不直接解锁曲率航行或超光速通信”；相位航行实际给中继站物流倍率。应把它们解释为后来突破的工程准备，不要追溯性宣称早已掌握究极科技。[S9]

已有资产 / 系统Ultra 延续角色优先使用方式
QuantumComputingArray、InterstellarTheoryNexus推算、建模与跨星区协同研究/工坊定向提高有效科研；先审升级继承，不新增同档同作用科研楼。
PhantomMaterialsFabricator、PhaseMaterialSynthesisArray新材料的上游保留钛合金、镍、电子元件、陶瓷等旧工业投入。
OrbitalSolarArray、OrbitalThermalManagement高能试验的供电与热管理先改良已有设施；没有新的功能差异时不造“Ultra 太阳能板”。
Shipyard、CampaignManager、SectorManager新材料的长期消耗出口与远征验证场先使用现有战役、维修、补给；类型克制另立新系统。
Research / Workshop知识门槛 / 付费工程改良Research 的前置是研究；Workshop 可要求研究与工坊。不要虚构研究已支持建筑/实验完成条件。
StoryManager文明对实验后果的记忆读取真实完成状态，不负责发奖、改研究或强行触发经济事件。

科技树设计检查

  • 计算、能源、材料三个方向并行准备，不能全部挤在同一条必点长链里；T5、T6 与材料线并行。
  • 第一包 T1/T2/T3/T5/T6 只用现有材料；T4 才引入新材料研究费，确保生产先于消费门槛。

  • 不要把“必须占领新星区才能研究”和“必须完成该研究才能到达该星区”同时设为硬条件。首次实验的原料必须能从已有工业取得。
  • 第二包的条件不能只写在说明文字或 UI：Manager 校验、研究入队/启动、存档恢复和测试均须一致。

                ├→ 后续验证站 / 试验环的持续维护

新资源上线时就要有持续用途：A1 同包开放“高场研究设施”，持续消费束缚态材料并提供研究力，形成“用先进材料维持科研”的战略取舍。只有在确认 A0 的现有定向增益不足以形成新决策后才引入这条链。若暂不做持续消费设施，就使用现有相位材料完成 A0，不提前发布束缚态资源。不能仅凭将来会有用途，就验收新资源闭环。

最小包的两种合法定案：A0 推荐先做“6 研究 + 4 工坊 + 0 新资源/建筑”，直接用相位材料试验投资取舍；A1 若要同步引入束缚态材料，则为“6 研究 + 4 工坊 + 1 新资源 + 2 新建筑”，两座分别是制造设施与持续消费它的研究设施。不要发布只有生产、没有持续用途的中间版本。T3 在 A0 中改为相位材料工艺突破，T4 消费现有相位材料；宏观束缚态名称与新配方留到 A1。

四项工坊建议：让同一批材料形成取舍

  1. 相位分选改良：定向提高相位材料产出良率；不要重复使用现有 PhaseMaterialCalibration 的相同名称和职责。也可优先扩展现有条目的后继。
  2. 高场组件标准化：降低拟新增设施的建造成本，复用 BuildingConstructionMultiplier；不降低普通资源容量，因为根本没有容量门。
  3. 高场科研阵列校准：A1 定向提高新研究设施的科研能力，和扩建/供电争抢束缚态材料；A0 则服务现有理论中枢。
  4. 舰体损伤隔离：材料付费换维修/补给相关改良，复用现有效果。注意维修、补给与伤亡减少并非同一指标，不能文案说减伤而实际仅降维修费用。

以上均为一次性工坊。若需要开关配方或选择运行模式，当前 BuildingState 没有现成运行开关契约；不要假定工坊可以随时撤销。首包的取舍来自材料投资顺序；第二阶段再开发可逆配置。

必须按消费端计算倍率

普通产出 = 基础产出 × 数量 × 效率
         × 建筑通用产能倍率 × 全局产能倍率
         × 建筑-资源定向产出倍率 × 资源产出倍率

普通原料消耗 = 基础消耗 × 数量 × 效率
             × 建筑通用产能倍率 × 全局产能倍率

电力 / 物流产出有自己的倍率；不可假定随普通资源产能同步提升。

所以“产线产能 +25%”通常也会提高原料吞吐，不能自动称为良率提升。多数通用增益采用加法叠加：1.20 与 1.25 通常合成 1.45，不是 1.50。奇点 value=1.25 是全局研究倍率增加 0.25，并非保证相对当前实际速度恰好提高 25%。维修/补给等倍率又可能按乘法累计，必须分别验证。[S10]

6. 玩法线路：从“攒够”进化到“运行得住”

Ultra A：产业取舍，不增加新状态系统

目标：玩家进入奇点后立刻有新一轮决策：同一批相位或束缚态材料，应该用于科研、产线良率、电力支撑，还是舰队维修？让旧工业继续有用，让新材料是能力转换媒介，而不是又一层纯等待。

可玩循环：识别当前瓶颈 → 选择研究或工坊 → 扩建/改良旧链 → 投入高场科研 → 更快获得下一项技术 → 为远征保留补给。主线不能要求每个工坊都购买，也不能用全部科技都是小倍率的方式伪装新玩法。

Ultra B：只增加一个核心机制——工程验证项目

推荐作为 Ultra 标志玩法：研究告诉你“可能成立”，项目证明你“能够稳定运行”。实验需要明确材料、持续供给和设施；准备不足时可以暂停，不因随机事件永久失去基础研究。

拟新增状态至少分为：未开放、可准备、运行中、供给暂停、验证完成。Manager 校验前置、设施、首付与每 tick 支出；State 保存进度、已付成本、运行状态和完成记录。UI 只发命令与解释瓶颈，仍复用统一模拟时钟。

  • 验证不是第二条普通科研条：项目的关键约束是连续或分段稳定供给、设施能力与复核条件。普通研究仍按 ResearchPower 推进。
  • 连续验证要可解释：不足时优先暂停、保留已验证阶段；如需重测，只回退当前小阶段，并提前显示规则，不清空整个项目。
  • 不伪造自动稳态：既有物流/电力是全局流量，并非逐设施优先级调度；第一版不承诺科研自动抢到最后一单位能量。新增优先级属于独立行为修改。
  • 不靠读档刷结果：首付一次、tick 支付原子性、完成奖励一次、加载后不能重复完成；进度不由 Story 反向驱动。
  • 离线按相同规则：不能简单用离线秒数乘初始效率穿过资源耗尽点；也不要离线触发不可逆文明毁灭。

Ultra C：把黑暗森林做成选择，而不是惩罚计时器

在验证项目可用后再讨论“可探测性”状态：高能试验、信标与某些航行提高远距离可探测程度；更快扩张换来更高信息外泄压力。低发射并非完全隐身，更不是消灭废热。建议先做有阈值提示、可停止项目、可撤回行动的安全版本。

三类可逆政策候选：高输出扩张（进展快、信号更显著）、克制发射（慢但暴露少）、分散生存（维护贵但减少单点失败）。现在没有政策/外交/威慑系统，不能靠三项互斥研究假装实现它们。不要首版同时开发外星 AI 与外交树。

战役应该检验什么

  • 先让新材料影响补给效率、舰队完备与损伤控制，沿用现有持续远征；不能只提高敌人数值。
  • “水滴式代差”若要成为规则，必须新增相互作用类型或特殊目标条件，并有可预知反制路径；不允许无提示投入整支舰队后脚本全灭。
  • 当前 SectorDefinition 只有星区前置与域等条件，没有独立 RequiredTechLevel / RequiredResearch。新增 Ultra 星区不能仅靠高费用或强敌假定玩家不会提前进入；需新增并验证时代/科技门，或延后发布该星区。[S11]
  • 不要让新资源唯一来源是打败需要该资源才能战胜的敌人；战利品和占领流可以缓解压力，不能替代主生产链。

9. 推荐实施顺序与规模

  1. 先把入口做可信：核对奇点实际耗时、科研升级继承、必需供给与最新真实运行；修正已确认文案漂移。原测试仍精确断言奇点 5.5e11，改费用必须同步审核测试契约，不能只改资产或硬删测试。[S13]
  2. 先做 A0 验证方向：6 项研究 + 4 项工坊，以现有相位材料、理论中枢、太阳能和舰队形成可观察投资取舍。T3/T4 使用现有材料版本，不假称新物质已出现。
  3. 确实需要新产业时再做 A1：1 种束缚态资源 + 制造设施 + 持续消费它的高场研究设施；资源源汇同包交付。二者并行于旧链，不直接替代旧科研与相位产线。
  4. 完成后才做 B：工程验证项目是第一个新核心机制；配分布式验证站与试验环，先验收交易、供给、暂停、离线和旧档。
  5. 最后讨论 C：时代锁定的新星区、可探测性、可逆政策和有限曲率航路。若基础框架未齐，只保留叙事悬念，不上线假按钮。
建议最终定调：Spacer 解决“能否到达与供给”，Ultra 解决“能否验证、稳定运行与控制后果”，Archotech 才讨论“能否改变世界的基本规则”。这样既有《三体》的技术代差与文明压力，也保留 Kingdom 的鼠族复兴、旧产业价值和放置经营本体。

本轮没有修改游戏代码、资产、配置、测试或存档。报告中的新增名称、配方方向、规模和系统均为设计候选；路线图冻结状态没有被自动修改。下一步应优先确认 A0/A1 的范围与奇点目标体验，而不是立即批量创建 Ultra 资产。
