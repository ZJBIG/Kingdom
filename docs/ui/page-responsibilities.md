# Kingdom 页面职责边界

页面必须各自回答不同的问题，避免把同一份 Tutorial 快照复制到多个
页面。

## Overview：现在做什么

Overview 是当前行动的唯一权威入口，负责显示：

- 当前目标；
- 当前阻碍；
- 推荐行动；
- 人口、核心资源和下一时代目标的摘要；
- 最近一次行动反馈。

## Era：如何推进时代

Era 只负责当前时代到下一时代的推进信息：

- 当前时代和下一时代；
- 真实时代研究前置；
- 真实资源条件；
- 条件完成进度；
- 当前时代阻碍；
- 进入后可用能力（机械结果，不是剧情正文）。

Era 不复制 Overview 的完整目标、阻碍和推荐行动。页面顶部只提供一条
“当前引导”入口，跳回 Overview。

人口、生产力和研究力如果没有出现在真实时代规则中，只能标记为发展准备度，
不能伪装成时代硬条件。

## Story：为什么这件事有意义

Story 负责鼠族文明复兴的背景和历史反馈：

- 文明背景；
- 已唤醒的章节；
- 本次行动的历史意义；
- 章节对应的真实 Research、Building、Workshop 或 Sector 导航。

Story 不显示当前目标、当前阻碍、推荐行动或完整下一时代条件。

## 功能页面

Research、Buildings、Resources、Workshop 和 Sectors 负责真实系统的详细
数据与操作。剧情和 Tutorial 只能导航到这些页面，不能在自身页面复制操作逻辑
或直接修改游戏状态。

## 修改检查

新增引导文案前必须先判断它属于“现在做什么”“如何推进时代”还是“为什么有意义”。
如果属于 Overview 的当前行动信息，不应同时添加到 Era 或 Story。

## 重复内容处理规则

三页可以引用同一份真实状态，但不能用同一段文案回答同一个问题：

| 页面 | 玩家要得到的答案 | 可以显示 | 不应显示 |
| --- | --- | --- | --- |
| Overview | 现在做什么？ | 当前目标、完成方式、阻碍、推荐行动、少量核心状态 | Tutorial 背景段落、已唤醒章节正文、时代条件明细 |
| Era | 怎样进入下一时代？ | 当前/下一时代、真实研究与资源条件、条件进度、条件阻碍 | 完整引导目标、剧情章节正文、重复的推荐行动卡 |
| Story | 为什么这件事有意义？ | 文明背景、章节、行动后的历史反馈、指向真实系统的导航 | 当前阻碍、完整时代条件、替代 Overview 的推荐行动 |

因此“当前时代”可以在 Overview 作为状态摘要出现，也可以在 Era 作为推进上下文出现；Story 只用章节所属时代标记，不再单独承担当前时代状态。剧情章节的导航只负责把玩家带到真实系统页面，不负责执行行动。
