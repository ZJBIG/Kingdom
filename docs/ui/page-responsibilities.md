# 页面职责

本文只记录容易混淆的页面边界；具体数值和内容以当前定义资产、Manager 和运行时日志为准。

## 页面入口

- `Overview`：回答“现在做什么”，显示当前目标、阻碍和推荐行动。
- `Era`：回答“如何推进时代”，显示时代条件；可通过详情按钮跳到对应研究、资源或建筑。
- `Research`：显示研究树、队列和研究详情。
- `Workshop`：显示工坊升级和购买状态。
- `Buildings`：显示普通建筑；`SectorBuilding` 不进入此页。
- `Sectors`：显示星区状态。占领星区后，星区行右侧才显示“建筑”展开按钮；未占领时不创建或加载其建筑菜单。
- `Resources`：显示资源状态和资源详情，不承担建造、研究或工坊购买。
- `Story`：显示叙事与历史反馈，只导航到真实系统页面，不直接修改游戏状态。

## 操作归属

- UI 只显示当前 State/Definition，并调用 Manager 命令；不保存权威数量、库存或购买结果。
- 研究进入队首后由 `ResearchManager` 自动支付；研究详情没有独立支付按钮。
- 建造和拆除由 `BuildingManager.TryBuild/TryDeconstruct` 处理。建筑详情不提供建造或升级按钮；普通建筑入口在建筑列表，星区建筑入口在对应星区菜单。
- 工坊详情主按钮只负责购买工坊升级，不显示研究详情文本。
- 时代详情主按钮只负责时代推进或跳转到对应详情。

## 状态与刷新

- 当前正在研究的目标在研究树和研究队列中使用金色 Outline；其他队列项、普通节点和选中态保持原有颜色。
- 切换详情对象必须清除上一对象的选择状态，避免旧研究状态污染建筑或工坊详情。
- 展开状态仅属于 UI 内存，不写入 Runtime State 或存档。
- 页面可见时刷新显示；刷新不得推进模拟或重复订阅。
