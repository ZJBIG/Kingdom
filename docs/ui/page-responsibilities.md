# 页面职责与详情操作

本文件唯一维护页面入口、详情按钮及选择态语义。布局/手势技术契约在UI技能维护，State/刷新/生命周期在 `docs/architecture/ui-boundaries.md` 维护；实际数值由当前Definition、State和Manager决定。

## 页面入口

| 页面 | 职责与入口边界 |
|---|---|
| Overview | 显示目标与导航、粮食/供应简报、净消耗生产链、可研究和工坊选择，以及聚落事件影响与恢复时间 |
| Era | 回答“如何推进时代”，显示时代条件；详情可跳到对应研究、资源或建筑 |
| Research | 研究树、研究队列与研究详情 |
| Workshop | 工坊升级与购买状态，不复用研究详情内容 |
| Buildings | 普通建筑；过滤全部SectorBuilding |
| Sectors | 星区状态；占领后行右侧才显示“建筑”展开按钮，未占领不创建或加载建筑菜单 |
| Resources | 资源状态和详情，不承担建造、研究或工坊购买 |
| Production | 独立生产节点图；资源根显示生产来源和持续投入，建筑根区分升级建筑与原料生产建筑，不混入建造费用或研究解锁树 |
| Story | 叙事与历史反馈，只导航到真实系统页面，不直接修改游戏状态 |

Era必须明确区分真实`EraGoalEvaluation`硬条件与发展准备度建议：硬条件显示满足/未满足，建议以独立建议样式标注，不参与时代推进判定，也不使用会被误读为硬条件的勾选待办样式。

## 详情主操作

| 详情对象 | 允许的主操作 |
|---|---|
| Research | 加入/移出研究队列；不提供独立付款按钮 |
| Workshop | 购买当前所选工坊升级，不显示研究详情文本 |
| Era | 时代推进或对应详情/页面导航 |
| Building | 无建造/升级主按钮；普通建筑在建筑列表操作，星区建筑仅在已占领星区菜单操作 |
| Resource | 无主操作按钮 |

- 队首研究由ResearchManager自动付款；支付/不足等待与台账契约见 `docs/architecture/research-queue-payment.md`，UI不得另行扣款。
- 建造/拆除调用 `BuildingManager.TryBuild/TryDeconstruct`，不在UI保存权威数量、库存或购买结果。
- 详情主按钮采用单按钮布局，左右各48像素内边距，由Prefab创作；不恢复贴满详情面板或双按钮支付布局。
- 详情按钮文字、可用性和委托来自当前对象及其Manager状态；切换对象必须清除上一对象的选择状态，避免旧研究状态污染建筑/工坊详情。

## 选择态与显示状态

- 普通建筑卡片按当前所选建造/升级数量，同时显示土地、生产力、材料的所有不足图标，不附加缺口文字；全部满足时显示普通材料图标。缺口数值、补足建议及已有建筑生产效率放在详情中。状态判断复用BuildingManager交易校验。
- 普通建筑卡片不显示名称下方的功能介绍，名称使用完整标题区域并放大；详情土地/生产力不足时显示“需求 x，缺少 y”，充足时显示“土地充足”或“生产力充足”，释放容量则显示“释放 x”。自定义数量输入框使用与数量按钮一致的深色金属边框，简短占位“数量”。
- 仅当前正在研究的目标在研究树和队列中使用金色Outline。等待项、普通节点、选中态及连接线不得因此变成金色。
- 展开/折叠与选择仅属UI内存，不写Runtime State或存档。
- 详情不显示定位列表/研究图或置顶按钮；列表保留自身置顶，来源文本链接保留真实导航。研究视图默认放大1.3倍；重置恢复这一缩放及左上起始区域。
- 资源、建筑、工坊（含远征支援）、星区及星区工程可置顶；列表先按置顶排序，再沿用原时代/稳定ID顺序，解锁与筛选条件不变。研究置顶保留图拓扑，只加名称标记。置顶作为本机界面偏好，以类别与稳定ID保存于PlayerPrefs，不写v1游戏存档；取消置顶恢复原排序。
- 资源和建筑详情提供独立Production页入口，节点图使用中央页面的独立视口、双轴拖动与缩放，外层列表滚动停用；按真实内容边界限制移动。节点短按更新右侧详情，保留当前图根与展开状态；再从详情打开树才改变根。返回该页保持图位置、缩放与展开，定位根节点按钮恢复根位置。详情仅保留打开独立页面的入口。
- 所有建筑来源分别展示，逐分支展开实际持续消耗，建造费用不作为生产投入；建筑下级明确标记“升级建筑”与“原料生产建筑”；升级目标不计入持续投入种数。折叠分支仅按可见节点占位，不预留隐藏子树宽度。星区持续产出与一次性占领奖励分开标识；速率为单建筑定义基础值。相同资源可出现在不同路线中，仅当前路径的循环停止展开。建筑使用名称与时代，无需图标。
- 生产树节点采用紧凑金属材质，只保留名称及关系提示；库存、产速和建筑数量查看右侧详情。
- 生产树只显示满足时代/研究/工坊/星区前置或已有数量的建筑；资源限于正库存/实际流量，以及这些建筑和已解锁星区的持续投入、产出或奖励。未解锁来源及升级目标隐藏，解锁后由集中刷新补入，保持展开状态、缩放和根节点视口位置。
- 可见页面刷新显示；刷新不得推进模拟或重复订阅。研究缓存页隐藏时的输入屏蔽遵循UI生命周期文档，不要求所有页面一律Deactivate。

回归场景见 `docs/testing/playmode-test-plan.md`；同一规则的测试断言不是第二份产品规则。
