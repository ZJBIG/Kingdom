# 页面职责与详情操作

本文件唯一维护页面入口、详情按钮及选择态语义。布局/手势技术契约在UI技能维护，State/刷新/生命周期在 `docs/architecture/ui-boundaries.md` 维护；实际数值由当前Definition、State和Manager决定。

## 页面入口

| 页面 | 职责与入口边界 |
|---|---|
| Overview | 显示目标与导航、粮食/供应简报、净消耗生产链、可研究和工坊选择，以及聚落事件影响与恢复时间 |
| Era | 完成「文明规划」后开放；回答“如何推进时代”，选择跃迁或条件卡后在右侧显示对应研究/资源详情，保持时代页 |
| Research | 第一座住房建成后开放；研究树、研究队列与研究详情 |
| Workshop | 工坊升级与购买状态，不复用研究详情内容；保留实际解锁规则，玩家界面不显示“工坊尚未解锁”文案 |
| Buildings | 普通建筑；过滤全部SectorBuildingDef |
| Sectors | 星区状态与驻留后内部勘探；占领后可查看和操作已配置的勘探，右侧“建筑”入口建设普通和勘探解锁的专属设施，未占领不创建或加载建筑菜单 |
| Resources | 资源状态和详情，不承担建造、研究或工坊购买 |
| Production | 完成工业研究「工厂制度」后开放；独立生产节点图；资源根显示生产来源和持续投入，建筑根区分升级建筑与原料生产建筑，不混入建造费用或研究解锁树 |
| Story | 叙事与历史反馈，只导航到真实系统页面，不直接修改游戏状态 |

时代页整卡作为详情选择入口，不提供“查看详情”按钮；跃迁研究的队列操作需明确标为时代跃迁课题，说明材料一次付清、研究完成才进入新时代。Era必须明确区分真实`EraGoalEvaluation`硬条件与发展准备度建议：硬条件显示满足/未满足，建议以独立建议样式标注，不参与时代推进判定，也不使用会被误读为硬条件的勾选待办样式。

## 详情主操作

| 详情对象 | 允许的主操作 |
|---|---|
| Research | 加入/移出研究队列；不提供独立付款按钮 |
| Workshop | 购买当前所选工坊升级，不显示研究详情文本 |
| Era | 时代推进或对应详情/页面导航 |
| Building | 无建造/升级主按钮；普通建筑在建筑列表操作，星区建筑仅在已占领星区菜单操作 |
| Resource | 无主操作按钮 |

- 研究费用只显示“需求量（现有库存）”，不显示已付/需求的分期支付形式。
- 队首研究由ResearchManager自动付款；支付/不足等待与台账契约见 `docs/architecture/research-queue-payment.md`，UI不得另行扣款。
- 建造/拆除调用 `BuildingManager.TryBuild/TryDeconstruct`，不在UI保存权威数量、库存或购买结果。
- 星区内部勘探按钮只发送 `SectorManager` 命令并读取其状态；专属建筑与直接建造、工坊购买、读档统一检查本星区探索完成条件。普通星区建筑只检查占领条件。
- 详情主按钮采用单按钮布局，左右各48像素内边距，由Prefab创作；不恢复贴满详情面板或双按钮支付布局。
- 详情按钮文字、可用性和委托来自当前对象及其Manager状态；切换对象必须清除上一对象的选择状态，避免旧研究状态污染建筑/工坊详情。

## 选择态与显示状态

- 顶栏八项指标使用独立图形和数值，长按说明含义；电力与物流在对应生产设施实际解锁前隐藏。研究力、资源和设施速率显示当前有效值，含对应全局/定向倍率、事件和幸福度；建筑详情的“每座建筑属性”显示定义原值，不含增益、当前开工率或停用状态；实际资源流量与各产出的生产效率单独显示最终结果。顶栏幸福度仅显示笑脸图标和百分比（保留三位小数），不附加生产效率图标或括号倍率。
- 普通建筑使用独立的锤子建设图标与推土机拆除图标，数量单独显示；长按显示建造、升级、下一工程名称或拆除语义。星区设施完成全部建设后隐藏建设按钮，分阶段巨构尚有下一结构时保留；巨构隐藏数量与按钮文字，使用独立MegastructureBuild简洁金色上箭头图案，普通设施保留数量与原建造动作；另一按钮为同风格的纯图案暂停／恢复，不显示按钮文字，长按解释“停用／启用”。按钮与普通建筑动作同为88×104，运行时显示红底暂停，停用时显示金底启用，使用独立创作的FacilityPause/FacilityResume图案。普通星区设施操作从左到右固定为建造、拆除、启用或停用；拆除使用与普通建筑相同图案和88×104尺寸，沿用原子退款规则；阶段式巨构不显示拆除入口，Manager同样拒绝拆除。停用保留数量、容量与永久工程记录，停止持续投入和产出，状态由暂停／启用图标及右侧详情说明。
- 普通建筑卡片按当前所选建造/升级数量显示土地与生产力不足图标；材料充足/不足图标和说明统一放在右侧详情，与土地、生产力状态并列。详情保留缺口数值和已有建筑最终生产效率，不再重复新增劳力需求、规则解释、土地补足建议和当前状态总结。状态判断复用BuildingManager交易校验。
- 普通建筑卡片不显示名称下方的功能介绍，名称使用完整标题区域并放大；详情土地显示本次建造/升级的需求与缺口，生产力沿用聚落当前总需求与总缺口，两者只用图标，不显示“可供”；充足时缺少为0，释放容量则显示“释放 x”。自定义数量输入框使用与数量按钮一致的深色金属边框，简短占位“数量”。
- 仅当前正在研究的目标在研究树和队列中使用金色Outline。等待项、普通节点、选中态及连接线不得因此变成金色。
- 展开/折叠与选择仅属UI内存，不写Runtime State或存档。
- 详情不显示定位列表/研究图或置顶按钮；列表保留自身置顶，来源文本链接保留真实导航。研究视图默认放大1.3倍；重置恢复这一缩放及左上起始区域。
- 资源、普通建筑及星区列表图钉使用56px点击区域与44px图形；资源图钉采用普通建筑图钉相同锚点、枢轴与图片/文字之间的位置；星区列表和设施卡分别使用SectorDesign下独立的透明中心九宫格金属边框，星云单独按比例裁切，禁止上下镜像或随九宫格压缩成横带；星区外框更完整、星云氛围更明显，设施子卡边框更轻，保留暗色可读中心；不叠加光轨；保持名称与状态可读，装饰不接收射线。星区设施不提供置顶，插图保持普通建筑的136方形尺寸；子卡增加上下留白并内嵌于父星区。中央卡只显示图片、名称、普通设施数量及动作；不显示待建设、已建成、可扩建等重复副标题；材料费用、持续投入产出和基础属性集中到统一建筑详情，不另设阶段详情按钮。巨构卡片显示最近已建成阶段的Label；详情显示当前阶段的Label/Description和下一阶段的Label/Description、需求及效果，全部完成后保留最终阶段名称与含义。工坊卡片复用普通建筑的尺寸、插图及时代列，保留购买按钮，不提供置顶按钮或偏好读写。
- 资源、普通建筑及星区可置顶；列表先按置顶排序，再沿用原时代/稳定ID顺序，解锁与筛选条件不变。工坊（含远征支援）和星区设施按时代从新到旧、同代稳定ID排序。研究置顶保留图拓扑，只加名称标记。置顶作为本机界面偏好，以类别与稳定ID保存于PlayerPrefs，不写v1游戏存档；取消置顶恢复原排序。
- 星区设施列表通过星区卡片右上角居中的紧凑箭头按钮独立展开／折叠；展开列表不再显示重复的“星区工程”标题，不显示左侧层级竖杠，初始收起；切页、列表重建保留本次会话展开态。建筑详情不再单独列出全局开工率；生产效率显示State中包含适用劳力、资源和流量约束的实际效率，不重复乘开工率。资源需求的名称与需求／库存数字同一行对齐，数字禁止换行并在有限范围内自适应字号。
- 资源、建筑和已解锁或已占领星区详情提供独立Production页入口，节点图使用中央页面的独立视口、双轴拖动与缩放，外层列表滚动停用；按真实内容边界限制移动。节点短按更新右侧详情，保留当前图根与展开状态；再从详情打开树才改变根。返回该页保持图位置、缩放与展开，定位根节点按钮恢复根位置。详情仅保留打开独立页面的入口。
- 建筑生产来源复用建筑列表的 BuildingManager.ShouldDisplay 规则：有存量的旧级保留，空旧级让位给最高已解锁级；来源按时代降序，同一时代保持定义顺序。逐分支展开实际持续消耗，建造费用不作为生产投入；升级分支继续按前置解锁显示，不受来源筛选截断，升级目标不计入持续投入种数。折叠分支仅按可见节点占位，不预留隐藏子树宽度。星区根列出当地可见建筑、持续产出和一次性占领奖励；当地建筑遵守占领、研究、工坊及内部探索前置。资源路径中的星区来源保持叶节点。相同资源可出现在不同路线中，仅当前路径的循环停止展开。建筑节点显示建筑 Sprite，星区节点显示星区环境图标。
- 生产树节点采用闭合金属卡片，图片铺满中央主体：顶部名称、右上展开按钮、中央大图、底部关系提示；库存、产速和建筑数量查看右侧详情。
- 建筑与星区图片在列表、生产树和预览中共用 KingdomUIArtworkFrame：紧贴图片的2px闭合细边与局部短角标，无黑色衬边或内留白，装饰不覆盖图片、不接收射线；悬停适度提亮图片。图片短按打开共用插图预览层，可缩放、拖动、重置，通过关闭按钮、遮罩或Esc退出。预览按创作好的外框留出适配空间。图片点击不替代名称的详情操作；生产树中从图片拖动仍移动整图。资源图标保留原显示和交互。原PNG保留，建筑/星区图像以1024上限、Mipmap和Trilinear采样导入，预览不依赖另存低分辨率源图。
- 生产树只显示满足时代/研究/工坊/星区前置或已有数量的建筑；资源限于正库存/实际流量，以及这些建筑和已解锁星区的持续投入、产出或奖励。未解锁来源及升级目标隐藏，解锁后由集中刷新补入，保持展开状态、缩放和根节点视口位置。
- 可见页面刷新显示；刷新不得推进模拟或重复订阅。研究缓存页隐藏时的输入屏蔽遵循UI生命周期文档，不要求所有页面一律Deactivate。

回归场景见 `docs/testing/playmode-test-plan.md`；同一规则的测试断言不是第二份产品规则。

- 巨构建设入口长按说明使用定义中对应的结构名称（如“大气采集平台”“低温分离系统”“总装与试验阵列”“环恒星集能带”），不显示“建设第N阶段”。星区摘要与右侧详情显示已建结构；名称打开统一建筑详情，扩建费用和收益默认指向待建结构；底层工坊顺序和永久购买记录不变。
- 巨构详情按当前状态显示本体费用、下一结构费用或已全部完成；材料库存、前置与阶段购买后集中刷新，无需重新打开。设施只能停用／启用，购买记录和永久收益保留。
- 普通建筑与星区设施共用必要基础属性及持续投入产出；只列适用非零项，每座满效率预览与当前实际效率分开。所有星区设施（包括巨构）不显示土地，普通建筑保留土地与建造缺口。研究力、人口容量、生产力、食物、电力、物流供需复用顶栏对应图标；粮食储存上限使用新HudFoodStorage图标。已有图标的基本属性只显示图标及带符号数值，不重复属性名；食物生产／消耗保留/s，其余基础属性不附速率单位；零值隐藏。电力与物流各只有一个有符号值，正供给、负消耗，详情不重复列聚落总供需；其他资源投入产出与其他页面仍保留速率单位。

## 列表与分区视觉

- 生产树节点保留304×374与288×288插图区域，标题和关系说明使用独立深色底板及细分隔线，展开按钮保持原位置和事件。
- 时代页分区使用金属标题底板与低饱和铜色闭合边框，保留完整时代名称、Title/Content绑定路径和既有动态高度计算。
- 音乐曲目行高76，标题、时长、播放和分类分别沿用50%/18%/14%/18%列布局；Prefab提供Category图形槽。背景装饰保留透明度，当前曲目与交替行底色仍由现有音乐刷新逻辑控制。

- 星区与设施分别使用独立九宫格金属边框：外层雕刻金属边，内层较轻的暗靛细边；边框中心透明，独立非对称星云使用EnvelopeParent等比裁切。NebulaViewport只裁切星云，外层内缩20、内层内缩8，不裁切同级Surface边框；右上折叠按钮使用实心深色底。星区收起高度264，136方形插图左内缩64、居于标题区垂直中心；子设施卡高224、两侧对称内缩96，136方形插图左内缩40并垂直居中，底部留白48。九宫格的角饰须完整落在固定角片，拉伸区只用直边，不放圆饰。不使用木纹或额外光轨。巨构建设／扩建使用简洁金色上箭头与短底座，无文字；动作按钮保持88×104。

- 建筑资源投入产出及建筑／研究／工坊材料需求共用KingdomUIDetailResourceRow预制行与深色细边九宫格外壳，禁止无sprite的整块灰透明底；保留图标、名称、数值的单行基线与原有单位。

- 建筑详情土地属性使用与顶栏一致的地图图标。最终效率直接显示效率图标紧接百分比，不设文字标题或额外换行；多产出倍率不同时保留产出标识，避免数值歧义。
