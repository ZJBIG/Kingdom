# 详情页交互约束

本文只记录容易产生歧义、且必须长期保持的交互语义。普通的控件创建和页面布局实现不在本文重复说明。

## 研究支付与当前目标

- 研究详情不提供独立的“支付资源”按钮。
- 研究进入队首后由 `ResearchManager` 自动支付；资源不足时保持等待，不得部分扣除资源。
- 当前正在研究的目标同时在研究队列和研究树中使用金色 Outline。
- 等待队列中的其他研究、普通研究节点、选中态和连接线不得因此变为金色。

## 详情操作按钮

- 研究详情的主按钮只负责加入或删除研究队列。
- 工坊详情的主按钮只负责购买工坊升级。
- 时代详情的主按钮只负责时代推进或对应导航。
- 建筑详情不提供建造或升级按钮；这些操作保留在建筑列表或星区建筑菜单。
- 资源详情不提供主操作按钮。

切换详情对象时，必须清除上一对象的选择状态，避免研究选择残留导致其他详情显示错误的按钮文字或委托。详情按钮文字和可用性必须来自当前详情对象及其管理器状态。

## 尺寸

详情主按钮使用单按钮布局，左右各保留 48 像素内边距。不得恢复为贴满详情面板宽度，也不得恢复独立的双按钮支付布局。
