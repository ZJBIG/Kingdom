# 列表信息与递归生产链

沿用现有石材底板、按钮材质和2640×1200的11:5参考比例。列表时代色条与半透明底色区分自然、石器、中世纪、工业、太空、超凡、超越时代；主内容与详情材质按当前时代轻微调色，不增加嵌套实体底板。

资源显示时代与用途摘要，建筑显示主要生产角色和定义基础速率，工坊显示用途及购买状态，星区显示所属星系、当前状态、进度和占领收益。列表长名称单行省略，详情保留完整名称。左侧独立置顶按钮与行详情、建造、购买按钮分别绑定；置顶不改变玩法状态。

生产树采用纵向资源→来源建筑→投入资源结构。多个建筑不是互相排斥的配方选择，全部作为独立分支保留，用户按需展开；这样窄详情栏无需横向拖动或自动图布局。缩进最多占四级宽度，更深层显式写层级。资源沿用已有图标，建筑用名称、时代、基础产出和解锁状态。展开、折叠和模式切换由同一个详情滚动所有者处理。

预览来自当前Definition的持续生产/消耗关系，并分离星区持续生产与一次性奖励。不计算自动配平、全局所需总量、最优路线或建造方案；基础速率不是当前库存和倍率下的实际吞吐量。循环只阻止当前递归路径，共享原料在其它来源下仍可展开。

可重创作入口：`KingdomCollectionAuthoring.Author`，内部创作列表/星区工程/详情置顶和生产树模板。固定层级在Prefab中保存，运行时只绑定展示与交互。行为契约以 `page-responsibilities.md` 为准。
