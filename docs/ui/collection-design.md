# 列表信息与递归生产链

沿用2640×1200的11:5参考比例。资源、建筑卡片按定义技术等级使用独立Prefab与ImageGen生成的时代材质，保留真实文字、数值、按钮和置顶控件；主内容与详情材质按当前时代轻微调色。

资源显示时代与用途摘要，建筑显示主要生产角色和定义基础速率，工坊显示用途及购买状态，星区显示所属星系、当前状态、进度和占领收益。资源、建筑标题预留两行并自适应字号，极端长度省略，详情保留完整名称。左侧独立置顶按钮与行详情、建造、购买按钮分别绑定；置顶不改变玩法状态。

七时代美术位于 `Assets/Resources/Art/UI/EraCards/`：原始时代用粗木与植物绳结；石器时代用打制石块；中世纪用木框、手锻铁件与皮革；工业时代用铆接钢板、通风槽和铜管；太空时代用航天分段装甲、蓝色矩形纹路和蓝白工作灯带；极致时代用一体化结构、青绿色蜂窝与层间光；远古科技用不对称斜向电路、紫色节点与接缝光。这三个科技等级延续既有研究节点的纹样和色彩，并使用明显的边缘氛围灯光。遵循时代工艺，克制装饰与光效，不采用网游装备框风格。中央保持暗色安静区域，九宫格缩放保留边角纹理。`KingdomPlannerAuthoring.Author` 创作页面与模板，`EraCollectionArtAuthoring.Author` 更新图片导入、材质和文字安全边距；重新创作背景会复用概览布局设置。

生产树按用户补充的异星工厂参考改为从上往下的资源→来源建筑→投入资源节点图，以折线连接。独立“生产树”页使用中央宽画布，资源/建筑详情入口切换图根；建筑根同时显示升级建筑与原料生产建筑，并标明关系，不包含建造费用。多个来源并排保留，父节点位于其分支宽度中心，分支按需展开，折叠时按可见层收紧占位；复用图手势处理双轴拖动与缩放，各轴按真实内容范围限制。资源和建筑均使用实际定义的插图，并显示名称、基础产出或解锁状态；保留完整时代名称。长名称省略，点击更新右侧详情并保留图根。展开折叠以点击节点位置为锚点，内容收缩到边界时允许必要的位移。状态使用既有集中刷新更新，不重建节点或重置滚动；切页保留展开和视图位置。

预览来自当前Definition的持续生产/消耗关系，并分离星区持续生产与一次性奖励。不计算自动配平、全局所需总量、最优路线或建造方案；基础速率不是当前库存和倍率下的实际吞吐量。循环只阻止当前递归路径，共享原料在其它来源下仍可展开。
