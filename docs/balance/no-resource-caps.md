# 普通资源无仓储上限规则

## 结论

除 `FoodAmount` 外，Kingdom 中的普通资源库存永远不设置容量上限。

## 禁止

- `ResourceState.Capacity`
- `Resource.MaxAmount`
- 普通资源达到上限后停止生产
- 普通资源仓库建筑
- UI 隐藏 Clamp
- 为了卡进度临时加入容量
- 复制《猫国建设者》的木材、矿物、金属等仓储门槛

## 允许的门槛

- 等比增长的建筑成本
- 加工链
- 科技前置
- 研究力
- 人口/劳动力
- 领土
- 电力和物流流量
- 军事补给
- 一次性工程
- 敌方强度

## Food 例外

`FoodAmount` 可以有 `FoodCapacity`。

粮食容量来源可以包括：

- 陶器
- 食物仓
- 冷藏
- 轨道粮仓
- 特殊科技倍率

粮食容量建筑不得同时提高普通资源容量。

## 设计原因

无限普通库存保留放置游戏中“长期积累”的满足感。进度控制应来自生产链和文明能力，而不是每隔几分钟被仓库硬卡住。
