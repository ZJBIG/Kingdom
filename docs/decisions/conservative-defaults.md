# Conservative product defaults

These defaults prevent Codex from inventing gameplay rules during UI work.

- Food remains a special value in GameState.
- UI visibility does not pause simulation.
- Music continues while SettingViewer is disabled.
- Offline progress is outside the current UI-redesign milestone.
- Research cancellation/refund behavior is unchanged unless explicitly specified.
- Resource shortage uses a uniform satisfaction ratio; no building-priority system is introduced yet.
- The visual direction begins with dark low-saturation medieval strategy styling, but final colors/fonts require user references.
- Target baseline resolution is 1920x1080; 1366x768 and 2560x1440 are required checks.
- Codex does not commit, push, install packages or upgrade Unity without permission.
