# 本恒星系探索与荒芜开发地合同

## 星球内部勘探与专属建设（2026-10-20）

占领仍决定是否可建立驻留及建设普通设施；少数地点另有独立的“星球内部探索”，进度不与占领百分比共用。当前只有碧池星、雷门环和曜心配置项目。玩家开始后持续供给配置的生产资料；缺料保留进度并等待补给，手动暂停保留进度且停止扣料，补足材料后自动恢复。每次只支付实际推进时段所需材料，探索完成立即停止消耗并登记发现，不赠库存或自动收入。不同星球可并行，同星球首批一个项目；共享材料按稳定星区顺序扣付。在线与离线使用同一结算逻辑，离线不购买工程阶段。

| 星区 | 勘探发现 | 持续投入 | 建设资格 |
|---|---|---|---|
| 碧池星 `AzurePool` | 穿透冰壳抵达液态冰下海 | Machinery、Electronics、Composite、RocketFuel | 唯一冰海方舟：产出食物与研究力，运行占用生产力、电力和物流，并持续消耗 Chemical、Machinery、Electronics、Composite |
| 雷门环 `ThunderGate` | 无人探测器下潜确认稳定大气采集窗口 | Machinery、Electronics、Composite、Ceramic、RocketFuel | 唯一低温推进剂厂及后续低温分离、并联精馏、轨道装载阶段；推进剂与物流能力实际生效 |
| 曜心 `HeliosCore` | 日冕及辐射环境观测确认集能轨道 | Electronics、Glass、Ceramic、TitaniumAlloy、RocketFuel | 曜心唯一戴森工程；四阶段逐次支付并即时增加真实供电 |

探索所需研究与各资源来源必须由探索奖励以外的既有生产和研究链提供。特殊建筑在星区建筑列表提前可见，并明确显示具体勘探锁因；普通设施仍只要求占领。建筑收益、维护及效率由既有系统结算；拆除唯一建筑停止收益，已购买的戴森或推进剂基地阶段仍保留，重建后恢复。

驻留前的本星系（`SectorDef.IsHomeSystem`）探索/殖民行动只消耗 Food 与配置的行动资源；驻留后的内部勘探按上节项目单独消耗生产资料。

2026-10-19用户确认：Sol母恒星系六个据点是等待开发的荒芜空间。探索成功只授予星区状态和
`TerritoryReward`开发面积；`ResourceRewards`和`OccupiedResourceRatesPerSecond`必须全部为空。
成功不赠材料，占领也不自动采集或持续生产资源；后续收益来自玩家实际建设及其能源、物流、人口生产力与原料投入。

后续开发复用已有`SectorBuildingDef`与建筑生产链：玩家占领后主动支付材料建造对应星区设施，设施接入现有能源、物流、生产力和持续原料供给。已授予的开发面积仍可用于普通建筑；星区设施使用已有绑定星区及限建数量，不额外扣本土领土空间，也不新增独立地图或殖民地生产子系统。
这里约束本恒星系六据点；系外区域可保留已有一次性战利品与有限战略产出，不能把它们的收益规则套回本地。
本星系驻留行动不使用敌方强度、攻击力或防御力作为门槛；这些字段只对远星战役有意义。驻留行动能否推进由已解锁状态、Food 与该星区配置的持续行动资源决定。探索技术效果提高驻留行动推进速度，不改变资源奖励规则；内部勘探不读取该速度倍率。

实施验收需确认六处定义的两类资源列表均空、开发面积保留，Validator与Manager均拒绝带本地自动收益的定义；
针对性测试需覆盖成功只加面积、占领后在线/离线不产生资源，以及玩家建筑仍正常生产。
本合同更新不等于资产和行为验证已完成，实际结果记录到同主题交接与验证报告。

## 主动开发的职责

2026-10-20按[唯一建筑与史诗建设策划](space-and-beyond-design.md#唯一建筑与史诗建设2026-10-20修订策划)实施首批：雷门是一座唯一低温推进剂厂；曜心是分阶段购买的唯一戴森球工程；碧池星新增冰海方舟。探索奖励只开放建设资格，不替代建设付款或运行维护。

| 星区 | 建设职责 | 与既有经营的连接 |
|---|---|---|
| 曙光环 `DawnRing` | 轨道研究设施 | 无大气干扰的观测实验平台提供真实研究力，持续支持本系开发与后续远航科技 |
| 碧池星 `AzurePool` | 碧池物流中枢 | 保留既有`EarthMoonLogisticsHub`稳定ID、绑定和物流职责；说明与冰海星球一致 |
| 终焉星 `Terminus` | 复合材料与机械综合厂 | 接续旧工业投入，补充两条相关材料产线，不按每种资源另建替代厂 |
| 碎冠带 `ShardCrown` | 矿料分选设施 | 在持续采掘和维护投入下提供已有矿料，交由既有冶炼与加工链使用 |
| 雷门环 `ThunderGate` | 唯一低温推进剂厂 | 大气取氢、分离与液化作为厂内流程，以既有化工及维护投入生产`RocketFuel`，不建立独立氢库存 |
| 曜心 `HeliosCore` | 定向能源阵列与唯一戴森球工程 | 利用近恒星环境采能；戴森本体先提供试验供电，再购买卫星、集能带与联控网三个扩建阶段，以真实供电支撑产业与远航准备 |

上一轮氢原料`Hydrogen`和采氢站的定义连同meta已移入可恢复归档，不再从运行资源目录加载；推进剂厂保留既有稳定ID/GUID。合并建造费计入原两设施投入，运行负荷计入加工所需的采集份额，不通过删除氢消费免费省掉采集成本。不会从大气直接开采原油或精炼燃料。成本、流量与限建数量仍以实际资产为数值来源，验证记录续写同主题交接。

戴森阶段沿用工坊原子付款及单次购买集合，前置读取真实本体、前序阶段、研究和星区占领。本体及全部扩建阶段都需要曜心占领，曙光环不能建设该工程。拆除本体停止建筑收益，已购阶段保留，重建后恢复；读档允许该状态。既有远航与Ultra准入不追加戴森完工条件。首版阶段提高集能效率，维护沿本体真实配方，不虚构阶段新增负荷。

## 环境、建设与科技的因果链

设施角色由地点条件决定，产出进入既有全局经营：曙光的无大气观测环境提供研究力；碧池冰海驻留点的轨道转运提供物流；终焉荒原承接结构材料和机械加工；碎冠小天体供给既有矿料；雷门气态巨行星的大气采集在厂内转为推进剂；曜心的近恒星轨道承接定向采能与戴森群。矿料仍需冶炼，结构件仍需工业加工，推进剂仍需化工与维护，能源仍需运行供给。

实际路线沿用同一条研究树：`OrbitalEngineering → HomeSystemSurvey → DeepSpaceFleet → InterstellarNavigation`。轨道工程先进入Spacer，测绘开放本系驻留；主动建设所得研究力继续推进科技，材料、物流、火箭燃料与能源支持工业扩张和远征备料。深空舰队、星际导航分别兑现现有系统能力，首次系外前沿`AlphaCentauri`还要求曜心占领；科研完成不能绕过本系驻留。

这些设施提供可经营的能力，不要求每一处都建满后才准研究。曜心驻留、星际导航与首次远航均不以戴森完工作为前置。特别是`PhantomMaterials`需要星际导航，`PhaseMaterialEngineering`再承接幽影材料，戴森最终联控阶段使用相位材料；它属于远航科技之后仍可继续建设的长期成果，不能反过来锁住星际导航。戴森本体与早期阶段可在本系开发期间建设，全部阶段始终归属曜心。

## 开发建议与首次系外的衔接

现有经营建议读取真实勘探预览，提示可开始、运行中、等待补给、手动暂停，以及发现后可建设的专属本体。正在运行的勘探优先于另一项未开始的可选开发；缺材料显示其实际名称，暂停不丢失进度。这里只给建议，不启动勘探、不付款、不代建。

已满足准入的系外目标优先保留主导航；可选本系开发作为并行建议展示，未开始或手动暂停的勘探不遮住首次远航。无待推进或可解锁的系外目标时，导航才指向当地开发。首次半人马座目标仍读取 LaunchCenter、测绘、星际导航、碎冠带与曜心占领；远征推进另读深空舰队、实际有效军力和持续补给，不新增戴森或冰海方舟完成门槛。
