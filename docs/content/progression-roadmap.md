# 文明内容路线图

## 核心体验

玩家管理一群鼠族，从原始聚落发展成跨星际文明。

每个时代都应同时推进：

1. 生存：粮食、人口
2. 生产：原料、加工、自动化
3. 知识：研究力、科技
4. 空间：领土、建筑占地
5. 组织：生产力、物流、能源
6. 冲突：防御、军队、外星战争

## 近期目标

先完成“原始→新石器→中世纪”可玩纵向切片。

这是首个正式内容版本，必须有：

- 早期食物选择
- 木/石/黏土/纤维
- 石器/石砖/陶器/布料
- 煤/铜/锡/铁/青铜
- 研究力成长
- 两次时代跃迁
- 真实资源取舍
- 无作弊可达

## 中期目标

人口和领土成为文明主轴。

- 住房决定人口容量
- 人口提供生产力
- 食物影响人口
- 建筑占领领土
- 研究和战争扩张领土

## 后期目标

- 中世纪：钢、工具、图书、市场、军队
- 工业：电力、物流、机械、化工、电子
- 太空：发射、轨道、舰队、星区
- 外星战争：占领领土、获得稀有资源
- Ultra/Archotech：恒星工程和文明升格

不要一次性做完全部时代。每个时代先做一个完整闭环。
