# PlayMode 测试范围

本文件集中维护玩家可见行为和跨系统回归场景，不记录固定的“当前通过数”。先核对现有测试与最新日志，再补实际覆盖缺口，不按旧清单重复新增。

准备数据使用定义和运行时状态；数值断言遵守根 `AGENTS.md`，综合验收门见 `docs/testing/acceptance-checklist.md`。命令、结果路径与保存隔离见项目开发技能 `references/validation.md`。

## 启动、模拟与保存

- 新档启动正确，前10分钟smoke覆盖真实生产、人口和研究进展。
- 关闭或切换页面时模拟、研究、音乐继续，返回后显示当前State。
- 保存/加载保留必要状态；后台/恢复不重复结算、不依赖UI活动状态。
- 使用公开强类型API、DTO及ManualTick；不复制历史反射测试，不操作用户真实存档。
- Huawei P40 Pro横屏、安全区和输入手感需要直接设备证据。

## 页面与交易

- 研究队首自动全额支付；资源不足时等待、不部分扣款、不越过队首支付后续项；详情没有独立支付按钮。
- 仅当前研究目标在研究树和队列中显示金色Outline；详情切换清除旧选择状态。
- 完成“本星系测绘”（稳定ID：`HomeSystemSurvey`）后，星区入口可用并能跳转；`InterstellarNavigation`只负责跨星系路线，不得成为本星系页面前置。
- 未占领星区不显示展开按钮、不创建建筑菜单；占领后能展开/折叠。星区菜单数量和状态动态更新，建造/拆除调用BuildingManager且不改本土领土使用量。
- Buildings页过滤SectorBuilding；建筑详情无建造/升级按钮，工坊详情只购买工坊升级，时代详情执行推进或详情跳转。
- 星区菜单展开后的行高、viewport/content尺寸为正，后续行按实测相对位置排列且不重叠，不依赖写死的transform坐标。
- 研究图验证入口及完整布局/触摸门槛只在UI技能维护；缓存页隐藏后不能接收射线、按钮或手势输入。

## 剧情回归

- 固定18章节顺序、正文200–300字符；章节数量/顺序属于离散内容契约，不是可调经济值。
- 模拟tick后自动完成，完成历史永久保留且不授予经济效果。
- 保存/加载拒绝缺失必需剧情段，以及未知、重复或跳序章节ID。

## 日志证据

星区布局记录 `[SectorBuildings]`：星区ID、折叠/展开高度、卡片数、viewport/content实测尺寸。资源不足、未占领和跳转失败记录实际blocker。

结果必须有本轮Unity Test Runner XML和日志、非零项目用例及必要行为覆盖。跳过关键行为不算通过；旧结果和确定性模拟器fixture不能替代本轮PlayMode验收。
