# Kingdom5 内容扩充建议包

复制本包内容到 Kingdom 仓库根目录后，让 Codex 先读取：

1. `AGENTS.md`
2. `ToDoList_Content_Next_2026-07-25.txt`
3. `.agents/skills/kingdom-economy-simulation/SKILL.md`（涉及科技树、资源、建筑或平衡时必读）
4. `.agents/skills/kingdom-content-expansion/SKILL.md`

本包不会直接修改游戏源码或 ScriptableObject。

它提供：

- 当前内容/数值静态审查；
- 普通资源无容量规则；
- 原始→新石器→中世纪纵向切片；
- 精确的第一轮研究与建筑建议值；
- 人口、领土、电力、太空和外星战争路线图；
- Codex 仓库级 Skill；
- 审计脚本与测试模板。

CSV 中数值是第一轮可测试基线。Codex 必须通过模拟和真实试玩调整，并报告偏差。
